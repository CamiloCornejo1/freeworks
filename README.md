\# FreeWorks



Panel de control web para la gestión de proyectos y entregables de freelancers.



\## Descripción



FreeWorks es una aplicación web desarrollada como MVP para facilitar la gestión de proyectos entre freelancers y sus clientes.



La aplicación permitirá visualizar proyectos, administrar entregables, consultar el progreso, registrar comentarios de clientes y controlar el estado de avance de cada proyecto.



\## Tecnologías



\- Angular

\- Django

\- Git

\- Docker
